mend is one patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits to a tree of text files, all or nothing. It finds the lines each edit names at the first of three matching tiers, prints what it changed or why it failed, and writes every change or none. See SPEC.md for the whole contract.

## Run it

```sh
node main.ts [options] [PATCH]
```
